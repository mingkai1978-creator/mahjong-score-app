# 🀄 麻將計分 App

一款輕量、免安裝的麻將計分網頁應用程式，支援手機與電腦瀏覽器直接使用。

## 功能特色

- 🎮 **遊戲設定**：自訂底注、台數金額、自摸抽水等規則
- 👥 **4人計分**：即時顯示各玩家分數與輸贏金額
- 🃏 **豹子支援**：支援豹子倍數計算
- 📜 **歷史記錄**：完整記錄每局結果
- 📱 **響應式設計**：支援手機、平板、電腦

## 使用方式

### 直接使用（無需安裝）

1. 下載 `index.html`
2. 用瀏覽器開啟即可使用

### 線上使用

可透過 GitHub Pages 直接在瀏覽器中使用。

## 下載

點擊右上角 **Code > Download ZIP** 或直接下載 [index.html](index.html)。

## 技術

- 純 HTML / CSS / JavaScript
- 無需安裝、無需伺服器
- 支援離線使用
